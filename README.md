# Barbershop

Android application for barbershop booking and shop management.

## Modules
- app: Main Android app module
- mylibrary: Shared Android library module

## Tech Stack
- Java
- Android SDK (compileSdk 32)
- Firebase Auth, Realtime Database, Storage
- Google Maps SDK

## Setup
1. Open the project in Android Studio.
2. Add your own Firebase configuration file at app/google-services.json.
3. Set your Google Maps key in local.properties:

	MAPS_API_KEY=YOUR_MAPS_API_KEY

4. Sync Gradle and run the app.

## Notes
- Workspace-specific files like .idea and local.properties should not be committed.
- Replace any third-party assets/screenshots with your own before publishing.
